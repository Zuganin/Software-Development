# 🛒 Микросервисная инфраструктура интернет-магазина (CW3, КПО)

## 📌 Описание проекта

Данный проект — полнофункциональная микросервисная система для интернет-магазина, реализующая:

- Управление заказами (OrdersService)
- Управление счетами и транзакциями пользователей (PaymentsService)
- Асинхронное взаимодействие между сервисами через Kafka (паттерны transactional outbox/inbox)
- Централизованный API Gateway (Kong)
- Хранение данных в отдельных БД (PostgreSQL)
- Полное покрытие ключевых компонентов юнит-тестами (xUnit + Moq)

---

## 🏗️ Архитектура 

1. **API Gateway** — маршрутизация и балансировка запросов (Kong).
2. **OrdersService** — REST API для управления заказами, интеграция с Kafka (outbox), хранение заказов в Postgres.
3. **PaymentsService** — REST API для управления счетами и транзакциями, интеграция с Kafka (inbox/outbox), хранение счетов и истории в Postgres.
4. **Kafka** — асинхронная шина событий между сервисами.
5. **PostgreSQL** — отдельная база данных для каждого сервиса.
6. **Docker Compose** — автоматический запуск всей инфраструктуры одной командой.

---

## 📂 Структура решения

- `OrdersService/` — сервис заказов: контроллеры, сервисы, репозитории, доменные сущности, outbox, интеграция с Kafka.
- `PaymentsService/` — сервис платежей: контроллеры, сервисы, репозитории, доменные сущности, inbox/outbox, интеграция с Kafka.
- `Tests/` — юнит-тесты для всех ключевых компонентов обоих сервисов (xUnit + Moq, InMemoryDbContext).
- `kong/` — конфигурация Kong Gateway.
- `docker-compose.yml` — инфраструктура: сервисы, Kafka, Postgres, Kong.

## 🌍 Доступные endpoints

🔗 API Gateway [Orders Service](http://localhost:8000/orders/swagger/index.html)
| Метод  | Путь                | Описание                    |
| ------ | ------------------- | --------------------------- |
| POST   | /api/orders         | Создать заказ               |
| GET    | /api/orders         | Получить все заказы         |
| GET    | /api/orders/{id}    | Получить заказ по id        |

🔗 API Gateway [Payments Service](http://localhost:8000/payments/swagger/index.html)
| Метод  | Путь                    | Описание                          |
| ------ | ----------------------- | --------------------------------- |
| POST   | /api/accounts           | Создать счёт                      |
| GET    | /api/accounts/{id}      | Получить счёт по id               |
| POST   | /api/accounts/deposit   | Пополнить счёт                    |
| POST   | /api/accounts/withdraw  | Списать со счёта                  |
| GET    | /api/accounts/{id}/transactions | История транзакций         |

## 🚀 Запуск проекта через Docker

### 📦 Сборка и запуск

В корне проекта выполните:

```bash
docker-compose up --build
```

Swagger доступен по адресам сервисов (см. выше).

В итоге все реализовано для на оценку 8, описанную в тз, на фронтенд не осталось времени.
